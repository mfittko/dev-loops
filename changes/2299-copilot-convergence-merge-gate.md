- **The sanctioned merge wrapper now gates on Copilot convergence (issue [#2299](https://github.com/mfittko/dev-loops/issues/2299)).** `evaluateMergePreconditions` gains a fail-closed `copilot_convergence` precondition that reads the current-head Copilot review body disposition through the same `classifyCopilotReviewBodyDisposition` detection the loop's `copilotBodyFeedbackUnresolved` uses (#2290), so the shared classification cannot drift (the 🔵 policy differs by design: the loop self-blocks, the merge gate treats it as conductor-overridable). A current-head 🟡 "Changes recommended" (or an unrecognized disposition header) refuses the merge; a 🔵 "Needs a closer look" is conductor-overridable (unresolved threads still gate it via `gate_evidence`); a 🟢 "Approval recommended", a stale non-approval at an earlier head, or no current-head Copilot review passes. This closes the merge-step fail-open where a current-head non-approval could merge past #2290's loop-level self-block.
