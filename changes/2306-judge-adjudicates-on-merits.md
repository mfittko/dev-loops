### Fixed

- **The first-round gate no longer auto-defers a finding on its severity label; the judge adjudicates EVERY finding (incl. lows) on merits, and the internal reviewer severity rubric is calibrated so a real correctness/fail-open defect is not under-labeled `low` (issue [#2306](https://github.com/mfittko/dev-loops/issues/2306)).** Observed on PR 2302: findings the internal draft-gate reviewers labeled `low` were re-surfaced by Copilot as HIGH/MID — real defects a severity-based auto-defer let through, costing a Copilot round. The judge guidance treated severity as an auto-gate (a `low` was `defer`-or-`reject` only, never `act`), so a genuine AC-relevant defect labeled `low` was ruled out of an up-front fix on its label alone. Two coupled prose/contract fixes, guarded by conformance tests (the judge and reviewers are LLM roles, so the durable fix is the briefing contract): (1) Disposition — `agents/judge.agent.md` and the Phase 3.5 judge contract in `skills/docs/gate-review-sub-loop-contract.md` now state that severity is an INPUT to the judge, never an auto-gate: a real defect (correctness, fail-open/fail-closed, security, AC-breaking) is `act` regardless of its severity label, INCLUDING a `low`, at round 1 (the cheapest fix point). ADR 0051's net-reduction filing bar is preserved unchanged — a genuinely cosmetic `low` still `reject`s, a `low`/`nit` still files nothing — and acting a real `low` in-PR files nothing, so it is strictly more net-reduction-friendly than deferring. The severity-axis fixer-triage rule now exempts a judge-acted `low` from the round-1 defer allowance (declinable only on reproduction grounds), so the label-defer cannot move one stage downstream. (2) Calibration — the reviewer-facing severity classification (`gate-review-sub-loop-contract.md` consolidation section + `agents/review.agent.md`) now rates any correctness break on a reachable path or any fail-open/security/fail-closed gap at least `medium`, never `low`, reserving `low` for a real defect with no operator-visible consequence, so the internal gate is independently sufficient rather than Copilot-dependent. Recorded as ADR 0078 (amends ADR 0051). Covered by `test/contracts/gate-judge-merit-disposition-contract.test.mjs`. Harness-agnostic.
