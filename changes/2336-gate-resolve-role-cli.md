### Added

- **`dev-loops gate resolve-role --angle <name> [--gate <g>] [--harness <pi|claude>]` resolves a gate reviewer's persona, focus prompt, and authoritative model tier from the fully merged config (issue [#2336](https://github.com/mfittko/dev-loops/issues/2336)).** A gate reviewer runs in a shell and cannot call `resolveReviewerRole` inline, so the composed fan-out briefing and the review agent now point reviewers at this CLI instead of an inline JS call or a raw grep of `packages/core/src/config/extension-defaults.yaml` — the raw grep misses the repo's `.devloops` merge-by-name and yields the wrong persona/model. The CLI fails closed: a `.devloops` layer that fails schema validation or parsing (surfaced as `configErrorCount`), or an unknown angle that resolves only to the generic fallback persona, sets `ok:false` and exits nonzero rather than silently returning the shipped default. Role resolution is gate-independent; `--gate` only reports the angle's surface `scope`.
