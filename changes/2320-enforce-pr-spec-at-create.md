### Added

- **`dev-loops pr create` enforces the PR-description spec at create time, not only at ready-for-review (issue [#2320](https://github.com/mfittko/dev-loops/issues/2320)).** `create-pr.mjs` now runs the same shared `validateTrackerBackedPrBodySpec` (`@dev-loops/core/loop/issue-refinement-artifact`) that `ready-for-review.mjs` and `pre-pr-ready-gate.mjs` use — no re-implementation — on the resolved `--body`/`--body-file` of a tracker-backed PR (one whose body carries a closing issue via `--issue` or a `Closes #N` keyword). A non-conformant body (missing Objective, In scope, Acceptance criteria / Definition of done checklists, or explicit Non-goals) fails closed at create with the identical `validate-pr-body-spec` error codes the ready boundary emits, before `gh` is invoked and before the linked-PR probe. One validator, run at both ends, never drifting. Issue-less `--lightweight` PRs carry no closing reference and stay exempt. A canonical conformant PR-body skeleton (`skills/dev-loop/templates/pr-body.md`) is added and referenced from the `LOCAL-PR-CREATE-CANONICAL` PR-authoring guidance so bodies are authored conformant up front.
