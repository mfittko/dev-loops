### Added

- **Coordinator verify-command delegation boundary under Claude Code (issue [#2082](https://github.com/mfittko/dev-loops/issues/2082)).** Extends the opt-in `DEVLOOPS_COORDINATOR_READONLY=1` coordinator boundary with a Bash denylist: the dev-loop coordinator (`agent_type: "dev-loop"`) must not run a known code-verification/build entrypoint inline (`bun run verify`, `bun test`, `vitest`, `npm test`, `npm run test`, and the analogous `build` script across `bun`/`npm`/`yarn`/`pnpm`) — it must delegate the run to a fresh worker subagent instead. Worker subagents (`developer`/`fixer`/`quality`/`review`) are unaffected. Enforced by `decideBashGate` in `packages/core/src/claude/hook-decisions.mjs` and the `PreToolUse` Bash gate hook, gated by the SAME flag as the existing coordinator write-guard boundary.
