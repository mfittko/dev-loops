### Added

- **Coordinator→worker delegation boundaries under Claude Code (issue [#2082](https://github.com/mfittko/dev-loops/issues/2082)).** Extends the opt-in `DEVLOOPS_COORDINATOR_READONLY=1` coordinator boundary with TWO enforced guard rails, both shipped in this same layer: (1) a **tracked-file write boundary** — the dev-loop coordinator (`agent_type: "dev-loop"`) must not `Write`/`Edit` a tracked repo file directly; it must delegate the edit to a fresh worker subagent (`developer`/`fixer`/`quality`/`docs`) instead. Ephemeral artifacts (`tmp/`, the scratchpad, sanctioned ledger paths) are gitignored/non-repo paths and fall through unaffected. Enforced by `decideCoordinatorWriteGuard` in `packages/core/src/claude/hook-decisions.mjs` and the `PreToolUse` Write/Edit gate hook. (2) A **verify-command delegation boundary** — the same coordinator must not run a known code-verification/build entrypoint inline (`bun run verify`, `bun test`, `vitest`, `npm test`, `npm run test`, and the analogous `build` script across `bun`/`npm`/`yarn`/`pnpm`, including `:`-namespaced sub-scripts like `test:extension`/`verify:docs`, the `npx`/`bunx vitest` and `bun x vitest` forms, and behind a `nice`/`timeout` wrapper — bare `nice`, `nice -n <N>`, bare `timeout <duration>`, or `timeout` carrying `-s <sig>`/`-k <dur>`/`--signal=`/`--kill-after=`/`--preserve-status`/`--foreground` before the duration; other `nice`/`timeout` flag combinations are a known, deliberately uncovered ceiling) — it must delegate the run to a fresh worker subagent instead. Enforced by `decideBashGate` in the same module and the `PreToolUse` Bash gate hook. Worker subagents (`developer`/`fixer`/`quality`/`review`/`docs`) are unaffected by either boundary. Both deciders normalize a plugin-namespaced `agent_type` (`dev-loops:dev-loop` → `dev-loop`) before comparing, so the boundary holds whether the coordinator's `agent_type` arrives bare or namespaced by the Claude Code plugin convention. Gated by the SAME `DEVLOOPS_COORDINATOR_READONLY=1` flag (default fail-open, adopt-safe); once a consumer repo opts in, the guard decision logic is fail-closed and non-bypassable by the coordinator itself.
