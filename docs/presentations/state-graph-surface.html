A single cycle

Observe. Resolve. Act once. Refresh.

1

Observe

Read the artifact, head, checks, threads, ownership, and approvals.

2

Resolve

Interpret one state and its allowed transitions.

3

Act

Execute one bounded mutation or wait.

4

Refresh

Rebuild truth before choosing again.

A fresh session can continue because durable facts carry the workflow forward.

The v1 backend boundary

One tracker seam; one GitHub-coupled PR plane

Provider seam

Issues and board / queue

The stable Tracker interface supports a registered provider. GitHub ships as the built-in default.

GitHub-coupled

Pull requests and delivery evidence

PRs, review threads, CI, Copilot review, head SHAs, and merge truth use GitHub in v1.

A future non-GitHub PR host needs its own independent seam.

09 / 12

Applicability

The change lifecycle spans greenfield and brownfield

Greenfield
  • new plan or tracker item
  • architecture established during refinement
  • tests and implementation grow together
Brownfield
  • existing behavior and history enter the evidence bundle
  • compatibility and migration constrain the solution
  • regression and contract gates grow stronger
The deferred second-repository pilot is a formal portability proof alongside existing operational use in both contexts.
