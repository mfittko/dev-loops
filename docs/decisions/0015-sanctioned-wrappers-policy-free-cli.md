# 0015. Keep policy in the loop: policy-free CLI helpers, sanctioned wrappers for every GitHub operation, hook-enforced

## Status

Accepted

## Context

Helper CLIs had accumulated policy and bypass flags (force re-request, skip checks, probe-only, poll intervals) that let an agent override loop contracts on a per-call basis, while agents also mutated GitHub through raw `gh` commands — producing non-draft PRs that deadlocked the draft gate, merges without gate evidence, and unparseable ad-hoc `node -e`/GraphQL pipelines. The flag stripping and policy relocation landed via [issue 486](https://github.com/mfittko/dev-loops/issues/486) / [PR 539](https://github.com/mfittko/dev-loops/pull/539) and [issue 547](https://github.com/mfittko/dev-loops/issues/547) / [PR 549](https://github.com/mfittko/dev-loops/pull/549), building on [PR 502](https://github.com/mfittko/dev-loops/pull/502). The wrapper surface grew through [issue 894](https://github.com/mfittko/dev-loops/issues/894) / [PR 897](https://github.com/mfittko/dev-loops/pull/897) (canonical `scripts/github/create-pr.mjs`), [PR 989](https://github.com/mfittko/dev-loops/pull/989) and [issue 993](https://github.com/mfittko/dev-loops/issues/993) / [PR 999](https://github.com/mfittko/dev-loops/pull/999) (read/edit wrappers), [PR 1141](https://github.com/mfittko/dev-loops/pull/1141) (`--jq`/`--silent` everywhere), and [PR 1391](https://github.com/mfittko/dev-loops/pull/1391). Mechanical enforcement arrived with [PR 1024](https://github.com/mfittko/dev-loops/pull/1024) (evidence-gated merge), [PR 1045](https://github.com/mfittko/dev-loops/pull/1045) (raw `gh pr create` blocked), [PR 1074](https://github.com/mfittko/dev-loops/pull/1074) (subagent external-write guard), and [PR 1228](https://github.com/mfittko/dev-loops/pull/1228) (OPS-NO-INLINE-INTERPRETER).

## Decision

We strip policy and bypass flags from all CLI helpers: the CLI is mechanism-only, policy resolves in the contract/config layer (`policy-constants.mjs` and the loop contracts), and derivable state is auto-resolved instead of being passed in. Every agent-level GitHub read and write routes through a sanctioned deterministic wrapper — `create-pr.mjs` always opens a draft, self-assigns, and rejects `--ready`; `view-issue`, `edit-issue`, `edit-comment`, `list-review-threads`, and `wait-pr-checks` cover the rest — with `--jq`/`--silent` guaranteed on every JSON-emitting command, and inline interpreters banned in coordinator flows. Enforcement is mechanical, not prose: pre-tool-use hooks block raw `gh pr create` outright, gate `gh pr merge` behind clean current-head draft-gate and pre-approval evidence, and block ad-hoc external writes from subagents. We rejected keeping per-call policy flags with stricter documentation (agents demonstrably used them as bypasses) and prose-only rules in contracts or memory notes (already proven to drift; a hook fires every time).

## Consequences

Correctness guarantees live in a deterministic tooling layer plus hooks instead of prose rules, which is what lets later guardrails — evidence detectors, draft-gate reconciliation, the merge gate — trust tool invocations as ground truth. Loop behavior becomes tunable in one place, the config layer, rather than at every call site. The standing commitment is that any new external operation must ship as a wrapper with its raw equivalent blocked, and the large `scripts/github` surface (forty-plus scripts) is the visible cost of that rule. When a helper's defaults are wrong, the fix goes into the contract or config layer at the source, never a per-call escape hatch.
